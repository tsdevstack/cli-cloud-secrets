# @tsdevstack/cli-cloud-secrets

Cloud secrets management for [tsdevstack](https://tsdevstack.dev).

Syncs application secrets to managed Secret Managers on GCP, AWS, and Azure (GCP Secret Manager, AWS Secrets Manager, Azure Key Vault). Push, diff, set, list, and remove secrets with environment isolation and per-service scoping.

## Source-available mirror

This repository mirrors the `@tsdevstack/cli-cloud-secrets` source from the tsdevstack monorepo. The package is bundled into the [`@tsdevstack/cli`](https://www.npmjs.com/package/@tsdevstack/cli) binary, so it is not published to npm or installed on its own.

To use it, install the CLI:

```bash
npx @tsdevstack/cli init
```
